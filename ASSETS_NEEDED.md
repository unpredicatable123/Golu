# Assets needed

Every visual is generated by code: the Blender scripts build and render every frame and sprite, and the web app draws the flames, glow, smoke, steam, petals and loader. The only assets this project cannot generate are the **audio recordings**.

The app runs without them. When a file is missing it falls back to Web Audio synthesis and logs `[golu] audio files missing, using synthesis: …` in the browser console:
- **Bells:** inharmonic partials with exponential decay.
- **Om:** a tanpura-like drone on a 136.1 Hz fundamental with a slow swell.

Recordings sound better and are recommended for the final site.

## Audio files

Place each file in `web/static/audio/` in **both** formats, `<name>.webm` (Opus) and `<name>.mp3`. Howler picks the first format the browser plays.

| File stem | Use (SPEC §5.4) | Length | Notes | Status |
|---|---|---|---|---|
| `om-loop` | Om chant; plays at 35%, ducked to 20% during rituals | 20–40 s (any length works; long files stream) | Loops; cut at a zero crossing, or give it short fades at both ends | **Supplied** by the project owner (`om-chant.mp3.mpeg`, 3:31): trimmed, normalised to −16 LUFS, 1.5 s fades, encoded to `om-loop.webm` (Opus 64k) and `om-loop.mp3` |
| `bell-large` | Large temple bell rung on Enter | 4–6 s | One strike with its full natural decay | Missing (synth fallback) |
| `bell-small` | Hand bell (ghanta): aarthi rhythm and ambient rings | 0.8–1.5 s | One crisp strike, so it can repeat 4 times per circle | Missing (synth fallback) |
| `nadaswaram-short` | Optional; plays softly on entering Steps 3 and 4 (the weddings) | 6–12 s | A short auspicious phrase (mangala isai) | Missing (skipped silently; no synth) |

**Loudness:** normalise each file to about −16 LUFS integrated, peaks at −1 dBTP. The config sets playback levels (`audio.*.volume`), so the files themselves should be full-scale.

**Licensing:** use your own recordings, or recordings licensed CC0 or CC-BY with attribution added to `README.md`. Do not use recordings from films, albums or temple broadcasts without permission.

**Encoding example** (ffmpeg is already required for the frames):

```bash
ffmpeg -i om-master.wav -c:a libopus -b:a 96k web/static/audio/om-loop.webm
ffmpeg -i om-master.wav -c:a libmp3lame -q:a 4 web/static/audio/om-loop.mp3
```

## Nothing else

There are no image, texture, model, font or video files to supply:
- **Fonts:** Noto Serif Tamil and Cormorant Garamond come from npm (`@fontsource`, SIL OFL).
- **Images and video:** every frame, door video, poster and sprite is rendered by `scripts/render_all.sh` and encoded by `scripts/encode_frames.sh`.
